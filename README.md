# Invelsoft LLC Website

Official website for Invelsoft LLC — a Microsoft Solutions Partner offering Microsoft 365, Azure & Active Directory, CRM (Dynamics 365) and ERP (Business Central) consulting services.

This is a separate project from `invelsoft-llp-website` and `CorePrint` — kept independent under the INVELSOFT GitHub organization.

## Stack
Plain HTML / CSS / JavaScript — no build tools or frameworks. Deployed via GitHub Pages.

## Structure
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services (Microsoft 365, Azure & AD, CRM, ERP)
- `shop.html` — Microsoft software/licensing catalog (Request Quote, no checkout)
- `contact.html` — Contact form
- `css/style.css` — shared styles
- `js/script.js` — mobile nav, form handling
- `assets/images/` — logo and other images

## Notes
- Contact form is front-end only for now (no email backend wired up yet).
- Domain (currently invelsoft.com, hosted on Namecheap) will be pointed to GitHub Pages later — email hosting (Namecheap mailbox / MX records) stays untouched.
